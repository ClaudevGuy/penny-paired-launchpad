# Penny Paired // Launchpad

A front-end concept for pairing high-velocity penny stocks into a single staged intent for Robinhood Chain.

## Run locally

```bash
npm install
npm run dev
```

## Notes

- Stock values are a static snapshot of Yahoo Finance's “Most Active Penny Stocks” screener.
- Wallet, chain, and trade actions are simulation UI only.
- This project is not affiliated with Robinhood or Yahoo Finance.
